These are cleaned-up, reusable versions of the prompts spoken or described in the final video, not a verbatim export of the Lovable conversation. Builds can differ between runs. The earlier staged preparation prompts are not the sequence filmed in this tutorial.

1. INITIAL PROMPT — USE PLAN MODE

Plan a focused AI video editor called Clean Take for short recordings. Users should be able to upload a recording, get a word-timed transcript, save editing preferences, receive AI cut suggestions, review suggestions, reverse cut decisions, and export an edited MP4.

Use Lovable Cloud and built-in Lovable AI, except for transcription: use ElevenLabs for genuine word-level timestamps. Preserve false starts and repetitions in the transcript so the AI can identify them. Use browser-based video rendering rather than a separate rendering API. Never overwrite the original recording. Limit this tutorial app to two-minute clips and 100 MB uploads. Propose a plan before building. Keep transcription and AI credentials server-side. Require sign-in for stored clips and paid requests, and enforce clip ownership and deny-by-default database/storage access rules on the server. Enforce file-size, duration and supported-format limits server-side before processing, plus per-user quotas and rate limits before paid requests. Do not trust a client-supplied user ID or storage path as authorization. Avoid logging recordings, transcripts or credentials.

2. AFTER REVIEWING THE PLAN

Build the approved plan. Keep this a focused short-video editor, not a complete professional editing suite.

Add agent integrations — an MCP server — to this app. Let an approved user's assistant list their clips, read the transcript, list suggested cuts and accept or reject a cut. SAFETY / COST NOTES

- Use your own ElevenLabs key. Enable only Speech to Text, choose a small usage cap and a short expiration for the tutorial, and enter the key only in the secure connector/secret field. Never paste it into a public prompt, screenshot or source file.
- Review suggested cuts; timestamps and AI suggestions do not remove the need to check the result.
- Keep the original file. Browser export creates a new MP4 and needs the tab to remain open.
- Lovable build credits, runtime Cloud/AI usage and ElevenLabs transcription are separate potential costs. This bundle makes no promise of a fixed free allowance or fixed build cost.
- Before letting other users consume paid transcription or AI, add server-side ownership checks, upload limits and usage quotas. Publishing a URL alone is not a complete production security review.
